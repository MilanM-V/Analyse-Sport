# Le moteur v2 : ce qu'il change, et ses résultats saison par saison

*2026-10-09 · branche `test` · suite de [COMBINAISON_PISTES_2026-10-08.md](COMBINAISON_PISTES_2026-10-08.md). Le nouveau moteur est prêt dans le code du bot, mais pas encore déployé. Résultats sur toutes les saisons où l'on a à la fois les stats et les cotes : 2023-24, 2024-25 (cotes jusqu'au 23/01/2025) et 2025-26 (cotes buteur seulement).*

---

## En une phrase

**Le moteur v2 prévoit mieux que le moteur actuel aux passes, et c'est prouvé sur trois saisons. Au buteur, il fait un peu mieux aussi, sans preuve nette ; mais mélangé aux cotes de Pinnacle comme le fait le bot, il bat Pinnacle plus nettement que le moteur actuel. En argent, impossible de départager les deux moteurs.**

## Les 3 chiffres à retenir

1. **Passes : amélioration réelle.** Sur les trois saisons (91 351 joueurs évalués), le moteur v2 fait **−0,63 millinat** par joueur par rapport au moteur actuel, fourchette [−0,93 ; −0,33]. Il fait mieux chaque saison.
2. **Buteur : un peu mieux, et devant Pinnacle.** Sur les trois saisons, **−0,31** [−0,62 ; 0,00] contre le moteur actuel : probable, pas prouvé. Mélangé avec Pinnacle (65 % moteur, 35 % Pinnacle), le moteur v2 bat Pinnacle de **−0,92** [−1,38 ; −0,45] sur 35 663 lignes, contre −0,72 pour le moteur actuel.
3. **En argent, rien ne se dégage.** Selon la saison, le v2 gagne plus (2023-24 : +65 U contre +49) ou moins (2025-26 : +10 U contre +29). Une saison de quelques centaines de paris varie de ±40 U par simple chance : ces écarts ne disent rien.

## Comment lire ce document

Les mêmes notions que dans le rapport du 08/10, en bref :
- **La log-loss** est une note de pénalité sur les probabilités annoncées : **plus elle est basse, meilleur est le moteur**.
- **1 millinat (mnat)** = 0,001 point de cette note par joueur évalué. C'est minuscule, mais l'écart qui sépare un bon moteur de Pinnacle se compte en millinats.
- **Pinnacle** est le bookmaker le plus précis. Le bot ne parie jamais avec la seule probabilité du moteur : il la **mélange** avec celle de Pinnacle. C'est ce mélange qu'il faut comparer à Pinnacle.
- **La fourchette [a ; b]** est l'intervalle de confiance à 95 % :
  - entièrement sous 0 : l'amélioration est réelle ✅ ;
  - à cheval sur 0 : elle peut venir du hasard 🟡.
- **Les saisons.**
  - **2023-24** a servi à choisir les réglages de mise : ses chiffres sont un peu flatteurs.
  - **2024-25** est la saison de contrôle.
  - **2025-26** n'avait jamais servi à rien choisir avant l'étude du 08/10.
- **Les lignes.** Deux ensembles différents :
  - « Toutes les lignes éligibles » : chaque joueur que le bot aurait évalué, avec ou sans cote. Il suffit pour comparer deux moteurs.
  - « Lignes cotées par Pinnacle » : seulement les joueurs que Pinnacle cotait, pour comparer à Pinnacle.

## 1. Ce qui change dans le bot

### Le moteur v2 : trois ajouts

| Ajout | En clair |
|---|---|
| **Correction lisse (Platt)** | Le moteur corrige ses probabilités brutes sur les matchs les plus récents. L'ancienne correction était un escalier : une centaine de valeurs possibles seulement entre 15 et 50 %. La nouvelle est une courbe lisse : plus de 14 000 valeurs. |
| **Un deuxième cerveau** | Trois réseaux de neurones s'ajoutent aux arbres de décision ; on fait la moyenne des deux avis. Ils sont faits avec scikit-learn, déjà installé : rien de nouveau à installer sur le VPS. |
| **La qualité des occasions (xG)** | 12 statistiques de la saison en cours : xG individuel, tirs dangereux, xG en avantage numérique, xG de l'équipe quand le joueur est sur la glace, départs en zone offensive, xG de l'équipe et de l'adversaire. |

**Ce qui ne change pas : la stratégie de mise.**
- EV ≥ 8 %, Kelly 1/6, un pari par match, plafonds par match et par jour.
- Mélange avec Pinnacle à 65 / 35 (buteur) et 90 / 10 (passes).
- Paper trading.

**Les données xG.**
- L'historique 2008-2024, tiré de MoneyPuck, est maintenant dans le dépôt.
- À partir de 2025-26, le bot reconstruit lui-même l'xG de chaque match : il croise les tirs publiés par MoneyPuck avec les présences sur la glace de l'API NHL. Il le fait chaque soir, plus un rattrapage complet à 7h (heure de Paris).
- Comparée aux vraies données MoneyPuck sur 300 matchs de 2024-25, la reconstruction concorde à 0,976-0,9996 (corrélation) selon la statistique.

**Le réseau de neurones scikit-learn plutôt que celui de l'étude.** Avant les calculs, on l'a comparé à celui de l'étude (torch), sur la saison 2023-24 seulement et avec les mêmes arbres. L'écart était de +0,10 mnat au buteur et de −0,01 aux passes : sous le seuil de 0,15 fixé à l'avance.

### Les défauts corrigés

| Défaut | Ce que ça faisait | État |
|---|---|---|
| Ré-entraînement hebdomadaire du VPS avec un seul algorithme (LightGBM) | Il pouvait remplacer le moteur validé par un moteur moins bon, dès ce dimanche aux passes | ✅ corrigé et **poussé** le 08/10 (le watchdog du VPS le déploie) |
| Jour du ré-entraînement | Dimanche au lieu du lundi prévu | ✅ poussé |
| Un ancien modèle de ré-entraînement servi après un changement de features | Le bot n'aurait plus émis aucun pick au déploiement du v2 | ✅ poussé |
| **Début de saison** : statistiques d'équipe calculées sur des matchs incomplets | Écart jusqu'à 16 tirs et 2,7 buts sur les moyennes « 10 derniers matchs » de l'adversaire, pendant les ~10 premiers matchs de chaque équipe, c'est-à-dire **en ce moment** | ✅ poussé |
| Journal des joueurs évalués sans la cote Pinnacle ni la probabilité finale | Impossible de juger le moteur en paper trading | ✅ poussé ; le suivi commence au déploiement |
| **Montréal absent des cotes historiques** : The Odds API écrit « Montréal » avec un accent | Les 130 matchs du Canadien de 2023-24 et 2024-25 (6 286 lignes cotées) manquaient à toutes les simulations, à la recherche de configuration et aux études ; 82 matchs de plus en 2025-26 | ✅ corrigé : ils sont dans les chiffres de ce rapport |
| Le simulateur ne calibrait pas comme le bot (défaut « H17 ») | Ses projections décrivaient un moteur un peu différent de celui servi | ✅ corrigé (§4) |
| Matchs joués de la saison à 0 en 2025-26 dans le simulateur | Toute simulation de 2025-26 aurait été fausse | ✅ corrigé |

S'ajoute un journal **Daily Faceoff** : les lignes et unités d'avantage numérique du jour, ainsi que les blessés, sont enregistrés à chaque vague. Il est sans effet sur les paris. Il servira à tester ces données dans 2-3 mois.

## 2. Résultat 1 : la précision, saison par saison

Écart de note **v2 − moteur actuel**, sur toutes les lignes éligibles, en millinats (**négatif = le v2 est meilleur**).

| Saison | Buteur | Passes |
|---|---|---|
| 2023-24 | −0,39 [−0,98 ; +0,20] 🟡 (18 040 lignes) | −0,42 [−0,91 ; +0,06] 🟡 (30 453) |
| 2024-25 | −0,43 [−0,93 ; +0,11] 🟡 (18 371) | **−0,62** [−1,08 ; −0,16] ✅ (30 537) |
| 2025-26 | −0,10 [−0,62 ; +0,40] 🟡 (18 214) | **−0,85** [−1,46 ; −0,26] ✅ (30 361) |
| **Les 3 saisons** | **−0,31** [−0,62 ; 0,00] 🟡 (54 625) | **−0,63** [−0,93 ; −0,33] ✅ (91 351) |

**Lecture.**
- **Aux passes**, le v2 est meilleur chaque saison, et nettement sur les deux dernières : c'est une amélioration réelle.
- **Au buteur**, il est meilleur dans les trois saisons, mais de peu. La fourchette des trois saisons touche zéro : c'est probable, pas prouvé.

|---|---|---|---|---|

| 2024-25 (jusqu'au 23/01) | −1,18 [−2,14 ; −0,22] | **−1,54** [−2,46 ; −0,64] | −0,48 [−2,12 ; +1,02] | −0,65 [−2,23 ; +0,91] |
| 2025-26 | −0,87 [−1,65 ; −0,06] | **−0,97** [−1,70 ; −0,23] | pas de cotes | pas de cotes |

Lignes : 14 617 / 7 309 / 13 737 au buteur, 16 067 / 8 522 aux passes.

**Lecture.**
- **Les deux moteurs, mélangés à Pinnacle, battent Pinnacle** sur l'ensemble des saisons.

- **Aux passes**, les deux mélanges font jeu égal contre Pinnacle. Le mélange y donne 90 % au moteur et Pinnacle ne cote qu'une partie des passeurs ; le gain du v2 aux passes se voit sur l'ensemble des joueurs évalués (§2).

**Le modèle seul**, sans Pinnacle, au buteur sur les trois saisons :

## 4. Résultat 3 : en argent

Paris rejoués avec les vraies règles du bot, au prix réaliste des books français (cote Winamax reconstituée), bankroll de 100 U. En 2025-26, seules les cotes buteur existent : la config de prod n'y parie donc qu'au buteur.

| Saison | Config | Moteur actuel | Moteur v2 |
|---|---|---|---|
| 2023-24 | prod (buteur + passes) | 545 paris, **+48,6 U**, ROI +7,9 %, z 2,6 | 455 paris, **+65,3 U**, ROI +12,7 %, z 3,2 |
| 2024-25 (jusqu'au 23/01) | prod | 179 paris, +5,4 U, ROI +3,4 %, z 0,8 | 108 paris, +4,4 U, ROI +5,0 %, z 0,8 |
| 2025-26 | prod = buteur seul | 495 paris, **+28,9 U**, ROI +9,7 %, z 0,7 | 478 paris, **+9,9 U**, ROI +3,6 %, z 0,3 |
| 2023-24 | buteur seul | 202 paris, +7,3 U | 125 paris, +19,9 U |
| 2024-25 (jusqu'au 23/01) | buteur seul | 98 paris, +12,7 U | 52 paris, +7,9 U |

**Lecture.**
- **Les deux moteurs gagnent chaque saison** au prix réaliste.
- **Aucun ne gagne systématiquement plus** que l'autre. Ces écarts sont du même ordre que le hasard : une saison d'environ 500 paris varie de ±40 U.
- **Le z** compare le gain à ce que prévoyaient les probabilités de Pinnacle. Il dépasse 2 seulement en 2023-24, la saison sur laquelle les règles de mise ont été choisies : c'est donc flatteur.
- **La pire baisse de la bankroll** (drawdown) atteint 35 à 38 U dans une saison, avec l'un ou l'autre moteur : il faut s'y attendre.

**Les projections du simulateur changent.** Pour la config actuelle, sur la saison 2023-24 ramenée à 180 soirées :

| Version du simulateur | Projection |
|---|---|
| Ancien simulateur (05/10) | +136 U par saison |
| Moteur actuel, rejoué correctement | +55 U |
| Moteur v2 | +73 U (et +9 U en contrôle 2024-25) |

L'ancienne projection était gonflée par deux défauts : le simulateur ne calibrait pas comme le bot (défaut H17), et les matchs de Montréal manquaient. Le simulateur (`simulateur.html`) et la projection du dashboard décrivent maintenant le moteur réellement servi.

## 6. Pourquoi le buteur gagne moins que dans l'étude du 08/10

L'étude annonçait **−0,61** au buteur en 2025-26 pour la même formule ; le moteur livré fait **−0,10**. Mesuré sur exactement les mêmes joueurs, l'écart se décompose ainsi :
- **le moteur actuel**, recalculé sur le processeur comme le fait le VPS, est lui-même meilleur sur cette saison que sa version de l'étude, calculée sur la carte graphique : **−0,31** [−0,71 ; +0,07]. La référence s'est améliorée, donc l'écart avec elle diminue ;
- **le moteur livré** est un peu moins bon que la combinaison de l'étude : **+0,20** [−0,06 ; +0,45]. Il utilise le réseau de neurones scikit-learn au lieu de torch, et des arbres calculés sur le processeur.

Les deux écarts sont du même ordre que le bruit d'un recalcul (±0,3 mnat). Sur les deux autres saisons, le gain au buteur est −0,39 et −0,43, comme dans l'étude. Aux passes, les chiffres sont identiques à l'étude (−0,85 en 2025-26).

## Glossaire

| Mot | En clair |
|---|---|
| **Calibration** | Faire en sorte que « 30 % » veuille vraiment dire « 3 fois sur 10 ». |
| **Isotonique / Platt** | Deux façons de corriger les probabilités brutes : en escalier (isotonique, l'ancienne) ou par une courbe lisse en S (Platt, la nouvelle). |
| **Réseau de neurones** | Autre famille de modèle, qui raisonne autrement que les arbres de décision. |
| **xG (expected goals)** | Qualité d'un tir : la probabilité qu'il devienne un but, selon sa position, son type, etc. |
| **xG sur la glace** | xG de toute l'équipe pendant que le joueur est sur la glace : mesure les occasions créées par sa ligne. |
| **Walk-forward** | Test honnête : le moteur est entraîné uniquement sur le passé, puis prédit la suite, comme en vrai. |
| **Prix réaliste** | Cote Winamax reconstituée à partir de Pinnacle et des books américains : il n'existe pas d'historique de cotes françaises. |
| **Drawdown** | Plus grosse baisse de la bankroll entre un sommet et un creux. |
| **z** | Écart entre le gain et ce que prévoyaient les probabilités de Pinnacle, en nombre d'écarts-types. |
| **U (unité)** | Unité de mise : 1 U = 1 % de la bankroll de départ dans les simulations. |

## Annexe — Méthode et reproduction

**Protocole.**
- Les deux moteurs sont entraînés uniquement sur le passé, par le harnais du bot corrigé (lignes triées par date), aux dates de ré-entraînement suivantes : 2023-10-01, 2024-01-01, 2024-04-01, 2024-10-01, 2025-01-01, 2025-04-01, 2025-10-01, 2026-01-01 et 2026-04-01.
- Calculs sur processeur, comme le VPS.
- Les lignes évaluées suivent les règles d'éligibilité de la prod.
- Les fourchettes sont obtenues par bootstrap sur les soirées (95 %).
- Les paris sont sélectionnés par `select_bets`, avec la config de `settings.toml`.

**Contrôles.**
- Avec les réglages par défaut, le nouveau code redonne exactement l'ancien modèle (écart 0).
- La reconstruction xG du dépôt est identique à celle de l'étude.
- La table de cotes rebâtie est identique sur les lignes communes : seules s'ajoutent les lignes de Montréal, et 58 médianes US changent à cause de doublons de graphie.
- L'inférence de début de saison redonne les mêmes features que l'entraînement : 0 écart sur les matchs 2026-27 du 05 au 07/10.

**Commandes.**

```bash
python nhl/scripts/build_odds_table.py          # cotes historiques (Montréal compris)
python nhl/scripts/simulate_roi.py --phase m0   # moteur actuel (~15 min)
python nhl/scripts/simulate_roi.py --phase v2   # moteur v2 (~30 min)
python nhl/scripts/engine_report.py             # tableaux de ce rapport -> nhl/reports/engine_v2_results.json
python nhl/scripts/search_config.py             # configurations du simulateur
python nhl/scripts/train_models.py              # modèles de prod v2 + simulateur régénéré
```

**Données.** MoneyPuck (moneypuck.com, usage non commercial), via son miroir public ; API NHL ; The Odds API (cotes 2023-25, et cotes buteur 2025-26 achetées le 08/10). Aucun crédit dépensé pour ce rapport.
